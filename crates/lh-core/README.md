# lh-core

Pure, deterministic code with no I/O and no clock: callers pass token counts and events, and get durations and decisions back. It holds two things: the cost, step and KV-geometry models, which the simulator and the gateway's throttle share, and the admission and placement policies, which only the gateway runs.

| Module | What it holds | Used by |
|---|---|---|
| `cost` | What serving a prompt costs from each tier, the E0 model fitted on the frozen box ([BENCHMARKS.md](../../docs/BENCHMARKS.md#tier-cost-model-resuming-an-agent-turn-e0)), and decode time | `lh-sim` |
| `step` | What one engine step costs from what it carries (step tokens, attention pairs and context, a prefill beside decodes), fitted by `lh-sim`'s `scripts/fit_step_cost.py` on three operating points of the frozen box | `lh-sim`'s contention model; `admission`'s prefill price |
| `admission` | Whether a request goes upstream now, waits or is refused: the E2 baselines (static cap, token reservation, flow control, preempt-resubmit) and Leaseholder's own policy (`leaseholder`, below), driven by arrivals, first bytes and departures (and the realtime sessions' turns), and the token estimate they share | `lh-gateway`'s admission point |
| `placement` | Which GPU node a new session goes to when the gateway fronts several: `dedicated`, `least-loaded` and `leaseholder` (below), from what each node holds | `lh-gateway`'s placement |
| `geometry` | KV bytes per token, the engine block and tier capacities in blocks | both |

**Policy `leaseholder`** (the gateway half of E2 arm 9, beside the engine's `make-room` variant) is a variant of `admission::Policy` beside the baselines, pure and without a clock like them. Realtime requests go upstream at once, never queued and never refused ([ADR-0003](../../docs/adr/0003-realtime-is-never-shed.md)). Background requests yield to the realtime sessions' turns, which the caller tracks from lifecycle events and reports as two counts (`Turns`: sessions whose user is speaking, and sessions in their critical window, from the end of the user's turn to the reply's first audio). Each mechanism can be switched off for the ablations:
- *headroom*: while sessions are armed (from speech onset, or only in the critical window), a background request goes upstream only if the estimated tokens of the background requests in flight and its own leave `headroom_tokens` of the pool free for each armed session;
- *throttle*: the background requests admitted in a critical window share a budget of predicted prefill time, each priced by the `PrefillCost` the admission point is made with (`Admission::with_prefill_cost`): a `step` model of the engine and GPU, and the engine's step budget (`--max-num-batched-tokens`), in whose steps a lone prefill of the request's new tokens runs after its session's last prompt. On the frozen box's fit, 512 tokens after a 30,000-token context take 269 ms, after none 38 ms. The policy carries no fit of its own: a different engine or GPU needs its own, from `lh-sim`'s `scripts/fit_step_cost.py`;
- *degrade*: a realtime request that arrives while the background requests in flight leave less than one turn's headroom free has its reply capped;
- *aging*: a request the caller has let wait long enough is admitted regardless (`Admission::age`), and is `oversize` if its estimate alone is over what the headroom leaves.

`Admission::held_back` gives the estimated background tokens the headroom holds back at the moment, which the gateway integrates over time to price false alarms. What E2 measured of the policy is in [ARCHITECTURE.md §6](../../docs/ARCHITECTURE.md#6-tested-and-not-adopted); the leases, prefetch and ledger attribution planned here were dropped ([ADR-0006](../../docs/adr/0006-the-engine-change-carries-the-realtime-tier.md)).

**Placement** chooses the node of a session that has none; KV never moves between nodes, so the caller keeps each session on its node and asks again only for a new session, one that idled out, or one whose node stopped answering. `placement::Policy::place` decides from a snapshot of each node (`placement::Node`: whether it is ready, the classes it serves, its requests in flight, its realtime sessions and how many are armed, and the estimated background KV it holds and leaves free), pure and without a clock like admission. A node that is not ready takes nothing, and ties go to the earlier node:
- `dedicated`: a node that serves the session's class, of several the one with the fewest requests in flight;
- `least-loaded`, the stock pool: the node with the fewest requests in flight;
- `leaseholder`: an agent session (background or interactive) goes to the node holding the least estimated background KV, in flight and waiting, then the fewest requests in flight; a call goes to the node with the fewest calls, then the fewest of them armed for a turn now, then the most free KV, so that its turns find headroom. Calls come first because a call stays for minutes and is armed for a few seconds of each turn: counting only those armed at the moment would put calls that start together on one node.

`cargo run --release -p lh-core --example estimate_error -- RUN/aiperf/profile_export.jsonl...` measures the admission token estimate's error against the prompt tokens an engine reported in an AIPerf replay.
